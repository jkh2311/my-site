이번 버전 핵심
- 대표사진과 규격사진을 절대 확대(upscale)하지 않음
- 원본 이미지에서 필요한 부분을 자르기만 하고 resize를 사용하지 않음
- CSS도 원본 크기보다 크게 늘어나지 않도록 width:auto / max-width:100% 적용
- 주민등록증·여권·운전면허증·외국인등록증 규격 예시는
  AI 이미지 속 작은 한글을 제거하고 사람 사진만 사용
- 사진 규격의 크기·촬영시기·안경·가능/불가 설명은 HTML 글자로 표시하여 선명하게 유지
- 자동차보험의 증명사진 관련 불필요 문구 제거
- 나머지 게시글 내용과 구조는 V5.2 유지
