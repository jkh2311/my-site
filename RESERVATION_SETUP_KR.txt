최초 1회 설정
1. 이 ZIP의 전체 내용을 GitHub 저장소 main 브랜치에 업로드/커밋합니다.
2. GitHub 저장소 Settings > Pages로 이동합니다.
3. Build and deployment > Source를 "GitHub Actions"로 선택합니다.
4. Actions 탭에서 "Scheduled Pages Publish" 실행을 확인합니다.

작동 방식
- main에 처음 올릴 때도 현재 시각을 확인하여 아직 시간이 안 된 글은 배포본에서 제외합니다.
- 예약 시각이 되면 GitHub Actions가 다시 배포합니다.
- 예약 전 글은 HTML뿐 아니라 홈/전체게시물/article-index/sitemap/RSS/site-index/네이버 제출목록에서도 제외됩니다.
- GitHub 예약 작업은 서버 상황에 따라 예정 시각보다 몇 분 늦게 시작될 수 있습니다.

주의
- GitHub Pages Source가 Deploy from a branch로 남아 있으면 이 예약배포 구조가 적용되지 않습니다.
- 예약 워크플로는 기본 브랜치에서 실행됩니다.
- 2026년 예약이 끝난 뒤에는 workflow의 schedule 항목을 제거해도 됩니다. 빌드 스크립트는 이후 네 글을 모두 공개 상태로 처리합니다.
